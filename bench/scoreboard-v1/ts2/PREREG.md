## 1. ts1과 같은 것

요청 본문(ts2/timed.mts = ts1/timed.mts), 모델 gpt-4.1-mini, 고객 15명·360문항·3회, 채점, 판정 T2~T5와 예상(4절).

## 2. 실행 규칙 (ts1 최종 규칙 그대로, 결과 보기 전에 고정)

- 예비 실행: 잘못된 timestamp 확인 요청 3개("not-a-date", "2026-01-12T99:99:99Z", null)가 모두 400이어야 한다. 고객 A 24문항 1회. 서버 오류(5xx) 1건까지 허용, 나머지 조건(답 있음·long-term·degraded 아님·gpt-4.1-mini·사용량·가려진 날짜 없음)은 정상 응답 전부.
- 전체 실행: 서버 오류는 기록하고 오답으로 세며 계속한다. **6건 이상이면 멈추고 점수를 내지 않는다(ts1과 같은 기준, 넓히지 않는다).** 4xx는 바로 멈춘다. 재시도 0회.
- 멈추면 다시 돌리지 않는다. 이번 시험지로 시각 기능을 재는 마지막 실행이다.

## 3. 실행 (Codex, 맥)

1. 새 시험용 키. `npx tsx bench/scoreboard-v1/ts2/run.mts pilot` → 통과하면 `full` → `ts2/score.mts > ts2/RESULT.txt`.
2. 시험 키 폐기. 키 값은 출력하지 않는다.

## 4. 예측과 판정 (결과 전 고정, ts1과 같음)

| 판정 | 내용 | 예상 |
|---|---|---|
| T1 | 확인 요청 3개 400, 예비 실행 통과 | 맞음 |
