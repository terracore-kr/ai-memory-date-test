# portability-v1 — 기억을 옮긴 뒤에도 맞게 답하는가 (사전 등록)

작성: Claude, 2026-11-27. 결과를 보기 전에 썼다. 작성 시점의 유료 호출은 0회다(가짜 응답 점검만 했다).
대표님 지시: 2026-11-27 09:27 "응 그렇게 해" — 내보내기 기능을 알리기 전에 "옮긴 뒤에도 원하는 기억을 찾는가"를 잰다. 실행 전에 비용 확인을 받는다(6절).

## 0. 앞선 실험과의 관계 (숨기지 않는다)

- scoreboard-v1 시험 1(11-23)의 결과를 본 뒤에 설계했다. Mem0 292/360, LangMem 290/360. 독립 검증이 아니다.
- modelswap-v3(11-22)에서 "줄 순서를 뒤집으면 정정 문항이 15개 중 1개로 떨어진다"를 봤다. 이번은 그 현상이 공개 도구가 실제로 내보낸 기록에서도 나는지 본다.
- 설계 중 무료로 확인한 것(모델 호출 없음, 결과 파일 1절에 다시 적힌다): Mem0 기록 467개의 created_at은 모두 2026-11-23(기억을 만든 날)이고 대화 날짜와 같은 것은 0개. 정정 60건에서 새 값이 옛 값보다 뒤에 있는 수는 Mem0 내보낸 순서 60/60, id 순서 32/60, LangMem 내보낸 순서 0/59, id 순서 31/59. 시험 1에서 Mem0 정정 정답 57/60(전부 "새 값이 뒤"), LangMem 44/59("새 값이 앞"이지만 LangMem 기록에는 "Today's date is …" 줄이 섞여 있다).
- belcore 제품 기능(내보내기 파일)은 이 시험에 들어가지 않는다. belcore 내보내기에는 대화 글이 없고(사실 기억은 고객사 DB의 대화 원본에 있다), 파일 항목 구성은 특허 검토에서 공개 보류다.

## 1. 자료 (고정)

- 고객 15명, 360문항, 채점 `grade` — scoreboard-v1과 같다. 답변 모델 openai/gpt-4.1-mini, 온도 0, 3회 다수결.
- 기억: scoreboard-v1 `memory.tools.json`(Mem0 오픈소스판 2.2.1 · LangMem 0.0.30, 11-23 한 번 얼림). **새로 만들지 않는다.** 기록 글은 한 글자도 바꾸지 않는다.

## 2. 조건

| 조건 | 모델에 보여 주는 것 | 무엇을 흉내 내나 |
|---|---|---|
| (기존) Mem0 / LangMem 내보낸 그대로 | 도구가 돌려준 순서의 기록 — 시험 1과 글자까지 같다. **다시 묻지 않고 시험 1의 답을 쓴다** | 옮기지 않음 |
| mem0-by-id | 같은 기록을 id(UUID) 순으로 정렬 | 가져온 쪽 저장소가 기본 키 순서로 돌려줌 |
| langmem-by-id | 같은 기록을 id 순으로 정렬 | 위와 같음 |
| mem0-with-timestamps | 도구 순서 + 각 줄 앞에 Mem0가 내보낸 `created_at` | 가져온 쪽이 내보낸 시각을 "언제"로 씀 |
| transcript | 6회차 대화 원본 전체 + 질문 (scoreboard-v1 시험 2와 같은 메시지, system은 PRODUCT_SYS) | 고객사가 대화 원본을 보관하는 방식. 옮겨도 보내는 메시지가 같다 |

- 답변 지시: 기록 조건은 ANSWER_SYS(scoreboard-v1 시험 1과 같음), transcript는 PRODUCT_SYS(같은 규칙을 대화 기록에 맞게 옮긴 글).
- transcript는 belcore 제품이 아니라 같은 답변 모델에 대화 원본을 그대로 준 것이다. belcore 제품의 같은 시험 결과(ts7 324/360)는 별도 제품 결과로만 함께 적는다.
- 4조건 × 360 × 3회 = 4,320회. 재시도 0, 동시 4.

## 3. 무료 확인 (결과 파일 1절)

Mem0 created_at 날짜 분포와 대화 날짜 일치 수, LangMem 시각 필드 유무, 정정 문항의 새 값·옛 값 줄 위치(내보낸 순서 / id 순서).

## 4. 실행 (Codex, 맥)

1. `npx tsx bench/portability-v1/run.mts --dry-run` → 보수 상한 약 $2.87(출력 200토큰 가정). 예상 실제 비용 약 $1.5. 중단선 $3.00.
2. 대표님이 금액을 확인하면 `npx tsx bench/portability-v1/run.mts`
3. `npx tsx bench/portability-v1/score.mts > bench/portability-v1/RESULT.txt`
- 오류가 나면 다시 돌리지 말고 기록 그대로 보고한다. `answers.jsonl`이 있으면 실행기가 멈춘다.

## 5. 예측과 판정 (결과 전 고정)

흔들림 폭 = max(2, 두 조건 각각의 회차 간 최대 차이).

| 판정 | 내용 | 예상 |
|---|---|---|
| P1 | Mem0 정정 60문항 다수결 정답이 id 순서로 옮긴 뒤 45개 이하(내보낸 그대로 57) | 맞음 |
| P2 | Mem0 id 순서에서 정정 문항이 새 값이 뒤일 때 80% 이상, 앞일 때 20% 이하 맞는다 | 맞음 |
| P3 | LangMem "말한 날짜" 30문항 다수결 정답이 id 순서로 옮긴 뒤 15개 이하(내보낸 그대로 24) | 맞음 |
| P4a | Mem0 + 내보낸 created_at의 "말한 날짜" 정답이 9개 이하(시각을 붙여도 좋아지지 않음) | 맞음 |
| P4b | 그 90개 답(30문항 × 3회) 중 2026-11-23을 답한 것이 10개 이상(내보낸 시각을 말한 날로 착각) | 맞음 |
| P5 | transcript 합계 320 이상, "말한 날짜" 25 이상 | 맞음 |
| P6 | transcript 합계가 mem0-by-id, langmem-by-id 각각보다 흔들림 폭을 넘게 높다 | 둘 다 맞음 |

틀린 예측도 그대로 적는다.
